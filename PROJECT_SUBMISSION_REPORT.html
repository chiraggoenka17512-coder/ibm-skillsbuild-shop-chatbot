1. Project Task & Objectives

As per the IBM SkillsBuild Activity guidelines, this project demonstrates a fully functional, ethical customer-support chatbot embedded inside a responsive modern shop webpage. The chatbot welcomes shoppers, helps answer common inquiries, guides product selection, offers promotional discounts, checks store opening hours, simulates package tracking, and connects customers with human support without collecting any sensitive personal data.

2. Minimum Chatbot Flow Implementation

The conversation lifecycle is structured according to the standard IBM 6-step flow:

1. Welcome
2. Ask Needs
3. Show Choices
4. Useful Info
5. Next Option
6. Support/Bye

3. The 5 Core Conversation Paths

Path User Needs & Queries PulseBot Response & Interactive Features
1. Product Information Clothing materials, sizing guide, organic certifications, best-sellers Presents organic cotton details, fit tips, interactive chest/waist measurement table, and direct "Add to Bag" buttons.
2. Store Timings Operating hours, weekend schedule, holidays, store location Details Mon–Fri 10am–9pm, Saturday extended hours (10am–10pm), Sunday hours, and Flagship Gate 3 pickup directions.
3. Offers & Deals Discount coupons, student promotions, first-order savings Provides verified promo codes: WELCOME15 (15% off), STUDENT20 (20% student discount), FREESHIP50.
4. Order & Delivery Help Track package, delivery speeds, 14-day return & exchange policy Includes a simulated live tracking lookup (ORD-101, ORD-202, ORD-303) with an animated progress bar and returns rules.
5. Contact Support Escalate to human associate, customer care helpline, email Provides toll-free line 1-800-785-PULSE, official support email, and generates a simulated callback ticket ID (#TICK-XXXX).
